Web Automation Macro

A small independent automation extension that records your browser actions as a reusable workflow — then replays them for you, even after a page reload.

Get it with the installer All extensions
Main features

What it does

Record steps

Record clicks, typing and navigation as a repeatable workflow — no coding required.

Edit mode

Open a recorded workflow, tweak individual steps, or add new ones without starting over.

Reload support

However many times the page reloads mid-way, your automation picks up exactly where it left off.

Who this is for

Handy for any repetitive browser task you find yourself doing on any website — not limited to HEWP. Record it once as a macro, then replay it whenever you need to, saving the manual clicking each time.

Get it

How to install

1

Download the main installer

Web Automation Macro is offered as an optional add-on during setup.

2

Enable it when prompted

Accept the browser extension prompt to add it to Chrome or Edge.

3

Record your first workflow

Open the extension, hit record, perform your actions once, then save.
