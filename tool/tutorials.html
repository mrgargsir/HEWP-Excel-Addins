📦 Installation guide

Five minutes, no technical skill required

1

Download the installer

Get Installer.exe — it includes the Excel Tool, Chrome/Edge extension and dependencies.

2

Run the installer

Double-click the downloaded file and follow the on-screen instructions. Default settings are the easiest.

3

Check Excel's ribbon

New tabs appear — Auto E. Tool, Templates, HEWP Auto, HEWP Manual, Extra Tool, Tool Help, Tool Settings — all ready to use.

4

Install the browser extension (optional)

You'll be prompted to add it to Chrome or Edge. For Edge, you can also search "HEWP extension" in the Edge store.

5

Set up Tool Settings

Activate the tool if asked, then set your unit, browser and district, and restart Excel.

6

Start working

Open any bill or estimate and start using the tool. Auto-updates are on by default.

Before you install:
  • Save and close all Microsoft Excel windows
  • Have your unique install key ready
  • If Windows shows a security warning, click "More info" → "Run anyway"
