Free auxiliary utility

Chrome / Edge Extension

A lightweight browser add-on that fixes portal UI bugs and adds convenience shortcuts. It does not upload, scrape or automate any HEWP data — that all happens inside the Excel Tool.

Included in the main installer All extensions

Important: All core portal automation — uploading estimates, e-MB bills, variations and downloading data — is built directly into the Excel Tool. This extension only runs in your browser to smooth over portal quirks.

Main features

What it fixes and adds

Smart dropdown search

Enhanced search with filtering for every dropdown on the portal — tender lists included.

Toggle-all checkbox

Select or deselect every checkbox on a page with a single click.

Enter-key glitch fix

Pressing Enter no longer clears your form on the HEWP portal.

Important bookmarks

A set of advanced bookmarks for faster navigation around the portal.

Dark mode

Reduce eye strain with a dark theme for better readability during long sessions.

Runs locally

No data leaves your browser — it only adjusts how the portal page behaves for you.

Get it

How to install

1

Download the main installer

The extension is bundled with the HEWP Tool installer — no separate download needed.

2

Accept the prompt during setup

You'll be asked to add the extension to Chrome or Edge — click "Add to Chrome" or the Edge equivalent.

3

Using Edge only?

Search "HEWP extension" in the Edge Add-ons store if it wasn't added automatically.
