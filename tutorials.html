📦 Easy Installation Guide

Follow these simple steps to install Estimation & Billing Tool. The entire process takes approx 5 minutes and requires no technical expertise.

Download the Installer

Click the download button to get Installer.exe. The installer includes Excel Tool, Chrome/Edge Extension and dependencies.

Run the Installer

Double-click the downloaded file and follow the on-screen instructions. Accept the default settings for the easiest installation.

Enable Excel Tool if required

Open Excel and check the ribbon. You'll see new tabs: "Auto E. TOOLS", "Templates", "HEWP Auto", "HEWP Manual", "Extra Tools", "Tool Help", "Tool Settings" etc. with all the features ready to use.

Install Chrome/Edge Extension (Optional)

During installation, you'll be prompted to add the Chrome/Edge extension. Click "Add to Chrome" when prompted for enhanced portal features. For Edge Extension, search hewp extension in edge store.

Tool Settings

Activate the Tool if asked. Then first set the Unit, Browser & District as per your choice and restart Excel.

Start Working!

Open any Bill or Estimate and start using the tools. Auto-updates are enabled by default to keep you current with latest features.

⚠️ Before You Install:
  • ✅ Save & Close all Microsoft Excel windows
  • ✅ Have your unique install key ready
  • ✅ During Installation, If Windows shows security warning, click "More info" → "Run anyway"
